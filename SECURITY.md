# Security policy

Report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/thruputchain/thruput-explorer/security/advisories/new).
Include the affected commit, reproduction steps, and expected impact.
Keep signing keys, access tokens, and personal data out of reports.

This policy covers the Explorer application. Report vulnerabilities in the
Thruput SDK, wallet, or node through that component's security policy.

Fixes target the current default branch. Use
[issues](https://github.com/thruputchain/thruput-explorer/issues) for ordinary bugs
and support questions.
